Enter your Cloudflare Worker URL and choose a model. Your API key is stored securely in your Worker — not in this app.

📋 Don't have a Worker URL yet?
1. Sign up free at cloudflare.com
2. Go to Workers & Pages → Create Worker
3. Name it my-ai-proxy → Deploy
4. Paste the worker.js code → Deploy again
5. Settings → Variables → add ANTHROPIC_API_KEY = your key
6. Copy your Worker URL and paste above
